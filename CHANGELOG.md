# Changelog

All notable changes to GameLingo will be documented in this file.

## [1.0.0] - 2025-08-25

### Added
- Instant text translation using Google ML Kit (50+ languages)
- Screen translation via OCR (MediaProjection + ML Kit Text Recognition)
- Floating overlay for in-game translation
- Translation history with search and management
- Google Sign-In with Firebase Authentication
- Cloud sync via Firebase Firestore
- Pro subscription via YooMoney (ЮKassa)
- 10 free translations per day
- Pro plan: unlimited translations, no ads, screen overlay
- Dark and light theme support
- Smooth UI animations and transitions
- Onboarding screen for first-time users
- Russian and English language support
