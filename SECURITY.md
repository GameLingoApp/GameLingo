# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability in GameLingo, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email: support.gamelingo.app@gmail.com

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We will respond within 48 hours and work on a fix.

## Data Privacy

- GameLingo uses on-device ML Kit translation — text is processed locally
- Translation history is stored locally on the device
- Firebase is used only for authentication and cloud sync (when signed in)
- No data is sold to third parties
